# Интерактивный выбор квартир (демо)

Статичная страница без сборки: `index.html` + изображения.
Экраны: комплекс → фасад корпуса → план этажа → страница квартиры (`#/flat/L-109`).
Данные тестовые. Отправка заявки в демо не подключена.

Запуск локально: открыть `index.html` в браузере или `npx serve .`
Деплой: Vercel, framework «Other», без команды сборки, корень репозитория.
