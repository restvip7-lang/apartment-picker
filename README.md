# Интерактивный выбор квартир (демо)

Демо для руководства и клиентов застройщика (Аланья): покупатель выбирает квартиру на рендере комплекса.
Сайт: https://apartment-picker.vercel.app (EN: `#/?lang=en`, TR: `#/?lang=tr`).

## Как устроено

- Статичная страница без сборки: `index.html` (весь CSS и JS внутри) + изображения.
- Экраны:
  - комплекс (`#/`);
  - корпус (`#/b/L`);
  - фасад с этажами (`#/b/L/facade`);
  - план этажа с быстрой карточкой (`#/b/L/f/1/q/L-109`);
  - страница квартиры (`#/flat/L-109`).
- Фильтры и язык передаются в ссылке: `?lang=ru|en|tr&t=1+1&min=&max=`.
- Языки RU / EN / TR. Все тексты лежат в словаре `D` внутри `index.html`, функция перевода `t('ключ')`.
- Просмотр плана: перемещение и масштаб, кнопка «Вписать», полный экран. Масштаб сделан через `viewBox` у SVG.
- Подборка (♡) хранится в `localStorage` без регистрации. При открытии статусы и цены перепроверяются.
- Режимы «Покупатель» и «Продажи». В «Продажах» видны сводка продаж и раскраска корпусов по доле проданного.
- Тур «Показать возможности» на 9 шагов.
- Режим «Разметить этажи» нужен, чтобы обвести корпус и линии этажей мышью. Результат выгружается как JSON для `GEO`.

## Данные

- Все данные **тестовые** и генерируются прямо в коде. Админки для статусов нет.
- Контуры корпусов на рендере `complex.jpg` хранятся в `GEO`: контур, верхняя линия, нижняя линия и число этажей.
- Подробно сделан только корпус **L**:
  - план этажа `floor-l.jpg`, 11 квартир 1+1;
  - контуры квартир в `KP` (в пикселях картинки), номера в `BADGE`;
  - планировки квартир `apt-01.jpg` … `apt-11.jpg`.
- Неизвестные значения (вид, aidat) показываются как «Уточняется». Площади комнат не выдумываем.
- Заявка в демо **никуда не отправляется**, и форма честно об этом сообщает. Текст заявки уже готов для Bitrix24.

## Что дальше (не сделано)

- Реальные статусы и цены. Варианты:
  - синхронизация с Bitrix24 (рекомендуется: сделка в «брони» или «продано» сразу меняет квартиру на сайте);
  - админка Payload в сайте `restvip7-lang/realestate`;
  - Google-таблица.
- Встроить подборщик в основной сайт `realestate` (Next.js + Payload) как компонент.
- Для продакшена нужен рендер 3000 px и больше и редактор точек в админке.
- Турецкий перевод стоит проверить носителю языка.
- Отложено по ТЗ: сравнение до 3 квартир, подтверждённые виды, стороны света, аналитика воронки.

## Запуск и деплой

- Локально: открыть `index.html` в браузере или `npx serve .`
- Деплой: проект Vercel `apartment-picker`, framework «Other», без сборки. Пуш в `main` выкладывается автоматически.
